# homebrew-freespin

Homebrew tap for [Freespin](https://github.com/nklmilojevic/freespin), a native
macOS replacement for Logi Options+.

## Install

The app:

```sh
brew install --cask nklmilojevic/freespin/freespin
```

The `freespinctl` command-line tool and daemon:

```sh
brew install nklmilojevic/freespin/freespinctl
brew services start freespinctl
```

Run either the app or the daemon, not both.
